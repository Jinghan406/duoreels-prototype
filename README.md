# Duoreels · Hi-fi prototype

AI Studio · Team 4. A clickable hi-fi prototype of Duoreels, the app where a creator and an editor review a video together.

Open `index.html` in a browser (or the GitHub Pages link). Everything on the phone is tappable; the left bar jumps to each part of the flow.

- Sign up → Home → New project → v1 / v2 / v3 review → approve → download and post
- Project page: vertical 9:16 video first, timeline under it, notes below
- Notes by voice, text, drawing on the video (pen, circle, arrow) and time ranges
- Editor side: invite, notes to-do, upload next version
