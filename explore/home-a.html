Film strip

Duoreels is about reels, so the screen borrows from real film: sprocket holes, edge codes, frame numbers. It feels like a contact sheet you are working through, not a generic list.

  • Sprocket rails down both sides of the screen
  • Each project card is a film frame with perforations top and bottom
  • Edge-code numbers in mono (DR·014A), like printed on film stock
  • New project button gets perforated edges
